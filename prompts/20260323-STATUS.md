## Fix

**Root cause**: [maplibre-gl-style-spec](vscode-file://vscode-app/Applications/Visual%20Studio%20Code.app/Contents/Resources/app/out/vs/code/electron-browser/workbench/workbench.html) was a stale extracted copy from the original tarball, not a live symlink to [maplibre-style-spec](vscode-file://vscode-app/Applications/Visual%20Studio%20Code.app/Contents/Resources/app/out/vs/code/electron-browser/workbench/workbench.html). The lockfile said `"link": true` but the actual directory wasn't a symlink, so `npm install` skipped it every time --- the rebuilt tarball with `blend-mode` was never picked up.

**What was done**:

1.  Fixed v8.json
2.  Rebuilt style-spec (`npm run build`)
3.  **Vendored** the rebuilt dist files directly into [node_modules] (bypass npm's stale cache)
4.  Regenerated [raster_style_layer_properties.g.ts]
